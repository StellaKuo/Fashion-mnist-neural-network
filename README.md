# 👕 Fashion-MNIST Classification using Neural Network

## 📌 Project Overview

本專案使用 **TensorFlow / Keras** 建立 Neural Network 模型，針對 Fashion-MNIST 服飾影像進行多類別分類與預測。

## 🛠 Technologies

- Python
- NumPy
- Matplotlib
- TensorFlow
- Keras


## 📈 Result

完成 Fashion-MNIST 影像分類模型，並透過 Test Accuracy、Training / Validation 曲線與 Misclassification Analysis 評估模型表現。
